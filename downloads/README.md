# Rabel Gestione per Android

`Rabel-Gestione.apk` è una versione di prova Android 10 o successivo. È stata
pubblicata in questo repository pubblico su richiesta del proprietario.

**Attenzione:** chiunque scarichi il file può estrarre l'accesso tecnico e
modificare il menù Supabase e il sito. Non contiene una password da inserire.
Questa build è firmata con una chiave di debug temporanea: le build future
con un'altra firma potrebbero richiedere la disinstallazione. Va ancora
verificata su un dispositivo reale prima del rilascio definitivo.
